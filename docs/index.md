## Матрица компетенций

=== "Инженерия и автоматизация"
    * **Python (Advanced)**: Разработка отказоустойчивых парсеров, скриптов автоматизации и автономных конвейеров данных (ETL). Сбор информации из защищенных сред (Selenium Headless, BeautifulSoup4, Requests, многопоточность, Pandas).
    * **Извлечение данных (Web Scraping)**: Точный захват изолированных бизнес-констант и динамических метрик с помощью сложных XPath-выражений (текстовые предикаты, оси предков/потомков) в условиях нестабильной и защищенной корпоративной верстки.
    * **Проектирование алгоритмов**: Создание сквозных автоматизированных процессов «под ключ», автономных демонов и реализация сложной логики на основе конечных автоматов (State Machines).
    * **Валидация данных**: Реверс-инжиниринг документов, глубокий парсинг, очистка и контроль целостности сложных вложенных структур данных (HTML / XML / JSON).
    * **Инфраструктура и контейнеризация**: Реализация методологии Docs-as-Code для ведения технической документации. Проектирование и разработка легковесных REST API на базе **FastAPI**, изоляция зависимостей и локальная контейнеризация приложений через **Docker**. Уверенное встраивание независимых микросервисов в существующий ИТ-ландшафт компании.

=== "Анализ данных и NLP"
    * **Обработка неструктурированных текстов**: Токенизация, лемматизация и нормализация текстовых массивов в условиях жестких синтаксических ограничений (обработка беспробельных и сложных восточных языковых структур с интеграцией Stanza, CAMeL Tools, Malaya).
    * **Семантический векторный анализ**: Применение трансформеров и энкодеров Hugging Face (LaBSE, RoBERTa) для математического расчета смыслового сходства (косинусное расстояние, векторные эмбеддинги) между массивами данных и автоматического выявления аномалий.
    * **Синтаксический анализ и NER**: Использование графов зависимостей (depparse) для контекстного вычленения именованных сущностей, терминов и автоматизированного контроля строгого соответствия техническим паттернам.
    * **Автоматизированный аудит**: Проектирование конвейеров текстовой валидации (включая методы обратной генерации) со сквозным формированием дифференциальных отчетов (Diff) для быстрого машинного и ручного контроля больших объемов данных.

=== "Системный анализ и архитектура"
    * **Системный и бизнес-анализ**: Сбор и формализация требований, декомпозиция сложной бизнес-логики и высоковолатильных математических моделей. Практический опыт **декомпозиции монолитных систем на микросервисы** с проектированием API-контрактов. Моделирование алгоритмов взаимодействия и сквозного маппинга данных с использованием нотаций визуального моделирования (UML).
    * **Регуляторное соответствие (Compliance)**: Проектирование и аудит ИТ-решений под строгие международные стандарты (аудит независимых тестовых лабораторий уровня GLI / BMM Testlabs), эквивалентные по уровню ответственности и критичности отказов стандартам MedTech-отрасли.
    * **Управление техническими рисками**: Проактивный анализ архитектурных уязвимостей (Bus Factor, накопление технического долга, изменения структур данных на стороне внешних платформ), разработка стратегий снижения рисков и проектирование API-контрактов.
    * **Архитектурная эргономика**: Реализация концепции декларативного управления (Configuration-as-Code) вместо избыточных графических интерфейсов, проектирование интерактивных систем самодиагностики для снижения нагрузки на команду поддержки.
